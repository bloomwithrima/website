# Friend Coaching — GitHub Pages

## Deploy
1. Create a GitHub repository, for example `friend-coaching`.
2. Upload `index.html`, `styles.css`, `script.js` and the `assets` folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch → main → / (root)** and save.
5. GitHub will show the public Pages URL.

## Before launch
- Replace the placeholder phone number, website, Facebook URL and Instagram URL in the contact section.
- The hero image is cropped from the supplied design screenshot for this demo; replace `assets/hero.jpg` with a licensed nature photograph for production.
